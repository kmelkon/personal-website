# personal-website

Karam Malkon's personal links page. A single static `index.html` — no build step.

Brutalist-lite: Space Mono / Space Grotesk, `#cc5f5f` on cream, dark/light toggle,
floating draggable shapes (press **G** for gravity).

## Develop

Open `index.html` in a browser. That's the whole app.
